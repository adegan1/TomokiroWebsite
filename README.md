# Personal Website

This is my personal website/portfolio, showcasing information about myself and the many projects that I have worked on and am proud of from over the years.

## Structure

- Hero section with name and slideshow featuring some clips from my favorite projects.
- About section with information about myself, what I do, my skills, and my resume.
- My portfolio with several projects that I am proud of from over the years. The drop down expands to show more.
- Get in touch section where you can find my social links. You can write and send me an email directly from here.

- **index.html** - Main layout and functionality of the site.
- **styles.css** - Stylesheet for all pages.
- **project-content.js** - File containing content for portfolio descriptions.
- **README.md** - This file. Basic information about the site.
- **resources** - Folder filled with relevant files used around the site.

## How to View

Simply open `index.html` in your web browser to see the website locally. This is also online at **andrewdegan.com**.
